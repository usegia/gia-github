# Actual source fixtures

Only allowlisted public GitHub captures belong here. Preserve source URLs, capture timestamps, hashes, and coverage. Never include token headers, email addresses, private organization membership, or unrestricted API payloads.

Fixture data enters PostgreSQL through the production importer. Updates require reviewing changes to independent expected query identities. Replaying captured GitHub data is a database integration proof, not a claim that GitHub currently returns the same values.
